- (decision) ROOT CAUSE: OperatorConsoleController.OnOutcomeEventReceived guards on IsCurrent(_feedContext) and silently returns when false. IsCurrent compares topology Fingerprint, which AspireJsonParser builds from name:replicaCount:endpoints of every resource. Stopping/starting corebank-api changes replica count and endpoint list, so the fingerprint differs from the one captured at feed start -- every CloudEvent arriving in that window is dropped before it can resolve a row OR reach Evidence. Later payments settle because the fingerprint returns to its original string once both replicas are back on port 5032. This is a DemoRunner reporting defect; the bank is not at fault.
- (decision) Reframes the PRD: the ask is no longer 'add a way to resume processing' (processing already resumes) but 'stop the console lying about recovery, and make the outbox payoff visible on screen'. Falsifiable prediction for Loek to check on the live console: Evidence has NO transaction.completed rows around 13:38:16, but does have them for 13:38:55+.
